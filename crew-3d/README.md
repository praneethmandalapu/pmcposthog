# Crew — 3D launch page (student prototype)

Student prototype. Not a real PostHog product. Sample data.

Vite + React + react-three-fiber + drei. All geometry is built in code; fonts are bundled; no network calls.

    npm install
    npm run dev       # local
    npm run build     # outputs dist/ (relative base, host anywhere)

Presenter: P or the "Play demo" button (~50s), arrows/space = next/prev, 1-5 jump, 0 = hero.
No WebGL or width < 760px falls back to a flat scrolling layout.
